A través de sus redes sociales, el líder norteamericano dio a conocer este miércoles que la Fraja de Gaza quedará bajo el mando de una nueva administración palestina. Lo anterior se concretará luego de que las entidades involucradas sellaran un entendimiento definitivo para disolver las milicias armadas en el sector.

El jefe de Estado enfatizó que este pacto representa un avance crucial para conseguir estabilidad permanente en Medio Oriente. Asimismo, recalcó que las comunidades israelíes podrán contar con mayores garantías de protección, evitando que el territorio palestino funcione como plataforma para atentados.

Según lo informado, la implementación de este proceso se desarrollará de manera gradual mediante distintas etapas estratégicas. Las autoridades internacionales seguirán de cerca el cumplimiento de cada uno de los puntos acordados para asegurar una transición ordenada.
